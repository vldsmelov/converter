# Frontend (Vite + React + TypeScript)

## Запуск в Docker
1. Поднять backend:
   - `docker compose up -d --build`
2. Поднять UI:
   - `docker compose --profile ui up -d frontend`
3. Открыть:
   - UI: `http://localhost:5173`
   - Keycloak: `http://localhost:8080`

## Основные экраны
- Накладные:
  - список,
  - карточка накладной,
  - расчет и генерация XLSX/PDF,
  - скачивание файлов.
- Создание накладной:
  - конструктор строк,
  - проверка правил конвертации,
  - передача `context.item_name` для корректного экспорта.
- НСИ:
  - ЕИ: список/создание/редактирование/удаление,
  - категории: список/создание/редактирование/удаление,
  - номенклатура: список/создание/редактирование,
  - упаковки: список/создание/редактирование/удаление,
  - правила: список + вкладки + создание/редактирование/удаление.

## НСИ: правила
- Страница правил разделена на вкладки:
  - глобальные,
  - правила категорий,
  - правила номенклатуры.
- Для каждого типа доступны действия:
  - `Редактировать`,
  - `Удалить`.
- Wizard правил поддерживает:
  - create (`POST`),
  - edit (`PUT`) по маршруту `/nsi/rules/:scope/:id/edit`.

## НСИ: упаковки
- В списке упаковок доступны:
  - `Редактировать`,
  - `Удалить`.
- Редактирование: маршрут `/nsi/packages/:id/edit`.

## Формат итоговых файлов
- Экспорт теперь ориентирован на UI-термины:
  - `#`, `Товар`, `Кол-во`, `ЕИ (в документе)`, `Оприходование`, `Статус строки`.
- В колонке `Товар` ожидается название номенклатуры.

## Проверка frontend
- Сборка:
  - `docker run --rm -v ${PWD}:/repo -w /repo/frontend node:20-alpine sh -lc "npm ci && npm run build"`
