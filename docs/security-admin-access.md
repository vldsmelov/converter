# Административный доступ (СБ)

## Требование

Администрирование хоста и контейнеров — **только через согласованный контур** (терминальный сервер, jump host, VPN + allowlist). Прямой SSH с произвольных адресов в интернет для прода не считается нормой.

## Проверки на хосте

```bash
# Кто слушает снаружи (ожидаемо: 22 только с allowlist, 80/443 для Nginx — по политике ИБ)
sudo ss -tlnp

# Правила фаервола (пример UFW; стек может отличаться)
sudo ufw status verbose
```
