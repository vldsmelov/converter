# Политика портов (СБ)

## Локальная разработка

`docker-compose.yml` публикует порты на все интерфейсы — **удобно для dev**, не является целевой схемой для внешнего контура.

## Прод (VPS)

`docker-compose.vps.yml`:

- Сервисы приложений: **`127.0.0.1:8001–8003`**, Keycloak **`127.0.0.1:8080`** — только loopback на хосте; снаружи виден **Nginx (443)**.
- PostgreSQL, RabbitMQ, MinIO **не** публикуются на хост — доступ только из docker-сети.

Проверка на сервере: `ss -tlnp` — не должно быть лишних `0.0.0.0:*` для сервисов стека (кроме согласованных с ИБ).
