# Политика портов (СБ)

## Локальная разработка

`docker-compose.yml` публикует порты на все интерфейсы — **удобно для dev**, не является целевой схемой для внешнего контура.

## Прод (VPS)

`docker-compose.vps.yml`:

- Сервисы приложений: **`127.0.0.1:18001–18003`**, Keycloak **`127.0.0.1:18080`** — только loopback на хосте; снаружи виден **Nginx (443)**.
- RabbitMQ management и MinIO console/API в compose доступны только на **`127.0.0.1`** для диагностики с хоста; PostgreSQL не публикуется на хост.

Проверка на сервере: `ss -tlnp` — не должно быть лишних `0.0.0.0:*` для сервисов стека (кроме согласованных с ИБ). Публичный `:5432` относится к `order_database` и не меняется в рамках Converter.
